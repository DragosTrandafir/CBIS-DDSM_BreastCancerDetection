# Lesion Type Classification in ROI Mammography Images

## Project Overview
This repository contains the technical documentation and research framework for my **Bachelor's Thesis** as an **Undergraduate Researcher** at the **MECO Group (UBB)**.The project focuses on the classification of lesion types within Mammography Regions of Interest (ROI) using advanced deep learning architectures.

## Technical Stack
* **Language:** Python 
* **Frameworks & Architectures:** Convolutional Neural Networks (CNNs) 
* **Techniques:** Advanced Data Augmentation, Modular Preprocessing Pipelines 
* **Evaluation:** Rigorous benchmarking using mathematical performance metrics across multiple state-of-the-art models 

## Key Contributions
* **Modular Pipeline Development:** Engineered a Python-based pipeline for automated medical image preprocessing and performance evaluation.
* **Architecture Optimization:** Collaborated with doctoral researchers to benchmark and optimize CNN performance for medical diagnostics.
* **Scientific Research:** Contributing to a research article documenting comparative results and lesion classification accuracy.
